Student Attendance Tracker — Modern Pro Edition

Files:
- index.html: page structure
- style.css: modern responsive styling
- script.js: attendance logic and theme toggle

Run:
1. Extract the ZIP.
2. Keep index.html, style.css, and script.js in the same folder.
3. Open index.html in a modern browser.

Highlights: student CRUD, attendance statuses, duplicate date protection, dynamic attendance percentages, search/filter, attendance history, low-attendance alerts, CSV export, Local Storage, responsive layout, and persistent dark mode.
Data is stored locally in the browser. Export CSV for backup.
